需求边界：接口、约束、逆向需求与未来要求

写操作：approve · reject · issue · return · refresh · disposal

约束

逆向需求

未来要求

- 普通用户不能修改库存和历史审计
- 高风险试剂必须教师审批 + 管理员复核
- 发放 / 归还必须在事务中完成
- 实际使用量 + 归还量 ≤ 发放量

- 不能绕过审批直接出库
- 不能出现负库存
- 不能删除关键审计事实
- 不能把演示数据当真实台账

- JWT 登录与细粒度角色权限
- 通知中心、移动端、报表增强
- 批次与处置记录进一步细化
- 法规规则可配置、可审计
